# TG万能签到

通过 Telegram **个人账号**，按目标逐行执行自定义命令、等待和按钮点击。由 gken6 维护，适用于 MoviePilot V3。

## 安装

在 MoviePilot 插件仓库管理中添加：

```text
https://github.com/gken6/MoviePilot-Plugins
```

刷新插件市场，搜索“TG万能签到”后安装。Telegram 依赖通过 `pyproject.toml` 声明，由 MoviePilot 安装。默认不启用、不使用代理、没有任何账号或目标配置。

## 首次登录

1. 在 [Telegram 官方应用管理](https://my.telegram.org/apps) 取得自己的 API ID 和 API Hash。
2. 填写 API ID、API Hash、带国家区号的手机号，保存插件设置。
3. 根据实际网络情况选择“不使用 / SOCKS5 / HTTP”代理；使用代理时填写自己的地址和端口。
4. 开启“保存后发送验证码”并保存，收到验证码后填写验证码，再保存。
5. 如果提示需要二步验证，填写自己账号的二步验证密码并保存。
6. 配置目标、动作及 Cron，启用定时任务；需要测试时开启“保存后立即执行一次”。

已有有效会话时无需重复登录。本插件不要求安装其他 Telegram 签到插件，也不附带账号、会话或 API 凭据。

## 配置目标与动作

目标支持 `@用户名`、数字聊天 ID 或 `https://t.me/用户名`，每行一个。动作与目标按**物理行号**对应，同一行多个动作使用英文分号 `;` 分隔。动作空行表示跳过对应目标，请保留占位空行。

示例目标：

```text
@example_bot_a
@example_bot_b
```

示例动作：

```text
/checkin
发送:/start;等待:2;点击:签到
```

支持普通文本、`发送:文字`、`点击:按钮文字`、`等待:秒数`，也支持 `send:`、`click:`、`wait:`。数字聊天 ID 自动转为整数。按钮文字会忽略装饰符号，若同一菜单匹配多个按钮则提示填写更完整的文字。

“每条命令等待回复秒数”控制回复等待时间，“命令间隔秒数”控制同一目标的动作间隔。默认 Cron 为每天 09:00，按 MoviePilot 的时区执行。

## 结果与数据

详情页展示最近七天的运行记录、目标、耗时和回复。通知可分别控制成功与失败。记录中的“成功”表示配置动作执行时未发生异常；没有回复时显示“未获取到有效回复”，不保证目标服务的业务签到结果。

新安装的 Telegram session 和历史保存在 MoviePilot 提供的插件数据目录，不写入源码目录。升级时若已有旧目录 `/config/plugins/tguniversalsign/data`，继续使用该目录，保持已有登录会话。不要把 session、运行配置或历史文件上传到代码仓库。

账号状态、登录和执行 API 均要求 MP 管理员权限。修改状态的接口仅支持 POST；验证码和二步验证密码通过 JSON 请求体提交。可通过插件设置完成全部操作，无需使用 API。

## 依赖恢复

容器重建后，MP 主服务可能先于 Telegram 依赖安装完成。插件启动时的导入失败不会再永久保留；每次创建客户端前重新检测，已就绪时不重复导入。依赖安装完成后可以直接重试，已有 Telegram session 和账号配置继续使用，不需要重新发送验证码。

依赖仍通过 `pyproject.toml` 交给 MoviePilot 管理，插件不自行运行 pip，也不在启动时触发签到或登录。仍未就绪时提示具体缺失的模块名，避免把全部情况笼统归为 telethon 和 python-socks 缺失。
